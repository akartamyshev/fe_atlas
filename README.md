This is the supplementary materials for the article:
A. I. Kartamyshev, S. V. Levchenko, D. A. Aksyonov, A. O. Boev. Atlas of heteroatomic chemical affinity in bcc Fe

Content:

fe.py - main script to train machine learning models
fe_data.py - script to prepare database to train machine learning models
machine_learning - folder containing scripts with a pipeline of training machine learning models
results - folder containing database (in subfolder 'results/sub-sub/data') and results of training
          XGBoost ('results/sub-sub/xgb'), Gradient Boosted Trees ('results/sub-sub/gbt'), and
          Random Forest ('results/sub-sub/rf') models

Requirements:

Install Python 3.14, xgboost, scikit-learn, pandas, matplotlib
